# connpass チェックインシステム（Google Apps Script）

connpass のイベント受付で使う、QRコードによるチェックイン管理システムです。
Googleスプレッドシートに紐づく Apps Script（コンテナバインド型）として動作し、受付端末のブラウザからカメラでQRを読み取って出席を記録します。

## できること

- 参加者のQRコードをカメラで読み取り、出席とチェックイン時刻を自動で記録
- 交通費補助の対象者を、読み取り時と一覧の両方で表示
- チェックイン済み／未チェックインの状況を一覧で確認（2秒ごとに自動更新）

## ファイル構成

| ファイル | 役割 |
|---|---|
| `Code.gs` | サーバー側処理（参加者の検索・記録・状況集計） |
| `Index.html` | 受付端末の画面（QR読み取りモード／状況確認モード） |

`Code.gs` は `SpreadsheetApp.getActiveSpreadsheet()` を使うため、**必ずスプレッドシートに紐づけた Apps Script（拡張機能 → Apps Script）として設置**してください。単体の Apps Script プロジェクトでは動作しません。

## 動作モード

起動すると「受付端末」として2つのモードを選択できます。

1. **QRコードでチェックイン**
   - 端末カメラでQRコードを読み取る
   - QRのURLから登録番号を抽出し、参加者リストを検索
   - 該当者がいれば C列に「出席済み」、D列にチェックイン時刻（`HH:mm:ss`）を記録
   - E列が「あり」の場合は受付画面に交通費補助の案内を表示
   - すでに「出席済み」の参加者は再記録せず、その旨を通知
2. **チェックイン状況を確認**
   - 2秒ごとに最新状況を取得して一覧表示
   - 「チェックイン済み」「未チェックイン」タブで切り替え、件数も表示

## スプレッドシートの準備

シート名 **「参加者リスト」** を用意し、1行目をヘッダーとして次の列構成にします。

| 列 | 内容 | 備考 |
|---|---|---|
| A | 登録番号 | QRコードから読み取る値と一致させる |
| B | 名前 | 受付画面・一覧に表示 |
| C | ステータス | チェックイン時に「出席済み」を自動記入 |
| D | チェックイン時刻 | チェックイン時に `HH:mm:ss` を自動記入 |
| E | 交通費補助の有無 | 「あり」のとき補助対象として扱う |

- データは**2行目以降**を対象とします（1行目はヘッダー）。
- C列・D列は空欄で構いません（自動で書き込まれます）。
- E列の交通費補助は必要に応じて手入力してください。

### connpass の CSV 取り込み

connpass からダウンロードした参加者CSVをインポートして配置します。

- QRコードから読み取る番号と一致する列を **A列（登録番号）** に配置
- 表示名を **B列（名前）** に配置
- C・D列は空欄、E列（交通費補助）は対象者に「あり」を設定

## セットアップ手順

1. Googleスプレッドシートを新規作成（または既存を利用）
2. シート「参加者リスト」を作成し、上記の列構成にする
3. connpass の CSV をインポートして A・B列を配置
4. メニューの「拡張機能」→「Apps Script」を開く
5. `Code.gs` の内容を、エディタのコードへ貼り付ける
6. エディタ左の「＋」→「HTML」でファイルを作成し、名前を **`Index`** にする（拡張子は付けない）。`Index.html` の内容を貼り付ける
7. 保存する
8. 「デプロイ」→「新しいデプロイ」→ 種類で「ウェブアプリ」を選択
   - 説明: 任意
   - 実行ユーザー: **自分**
   - アクセスできるユーザー: 受付端末から開ける範囲で設定（例: 全員）
9. 「デプロイ」を押し、初回は表示される権限の承認を行う
10. 発行された **ウェブアプリのURL** を受付端末のブラウザで開く

> 動作確認は、Apps Script エディタから `doGet` や `checkInAndRecord` を直接実行し、ログ（表示 → ログ）で確認できます。

## 受付時の操作

1. 受付端末でウェブアプリのURLを開く
2. 「QRコードでチェックイン」を選択
3. カメラの使用を許可し、参加者のQRコードをかざす
4. 画面に名前・結果（チェックイン完了／既にチェックイン済み／エラー）と補助の有無が表示される
5. 別端末で「チェックイン状況を確認」を開くと、随時最新の状況を確認できる

- 「左右反転」ボタンで前面カメラのミラー表示を切り替えられます（設定はブラウザに保存）。

## カスタマイズ

`Code.gs` 冒頭の定数で列構成を変更できます（**インデックスは0始まり**）。

| 定数 | 内容 | 既定値 |
|---|---|---|
| `PARTICIPANT_SHEET_NAME` | 参加者シート名 | `参加者リスト` |
| `ATTENDANCE_COL_INDEX` | ステータス列 | `2`（C列） |
| `TIME_COL_INDEX` | チェックイン時刻列 | `3`（D列） |
| `SUBSIDY_COL_INDEX` | 交通費補助列 | `4`（E列） |

出席判定に使う文字列は「出席済み」、交通費補助の判定文字列は「あり」です。変更する場合はコード側の文字列も合わせて修正してください。

## 注意事項

- スプレッドシートに紐づいた状態でのみ動作します（`getActiveSpreadsheet()` を利用）。
- カメラを使用するため、HTTPSで開けるブラウザが必要です（GASのウェブアプリはHTTPSで提供されます）。
- QRコードの登録番号は、**URLの末尾から1つ前のパス要素**を取り出して判定しています（6文字以上の場合のみ有効）。connpass のQR形式が変わった場合は `extractRegisteredId()` の調整が必要です。
- 状況確認モードは2秒間隔でサーバーに問い合わせます。多数の端末で同時に開くと負荷が増える点に留意してください。
- 複数端末から同時にチェックインした場合、同一参加者に対して処理が競合する可能性があります。
